# ✂️ Manipulação e Fatiamento de Strings em Python

Script modular desenvolvido em Python para demonstrar a limpeza de espaços em branco (`.strip()`) e o fatiamento de caracteres (*string slicing*) utilizando boas práticas de organização de código (`def`, `return` e `main()`).

## 🎯 Objetivo do Projeto
Praticar a construção de funções reutilizáveis e compreender a indexação de strings em Python (contagem iniciada em `0`), aplicando técnicas básicas de pré-processamento de texto.

## 🛠️ Conceitos Aplicados
- **Funções Modulares (`def` / `return`):** Isolamento da lógica de limpeza de texto em uma função dedicada (`sem_espaco`).
- **Limpeza de Texto (`.strip()`):** Remoção de espaços desnecessários no início e no final da string.
- **Fatiamento (*Slicing* `[inicio:fim]`):** Extração de trechos específicos de uma string através de seus índices.
